# 仓库整理验证

> 当前正式模拟验证为 [FullWindow 4 mm/s](FULLWINDOW_BASELINE.md)，已完成完整 GPU
> 重训及 95 ms 初态反演，不是下面的历史短测。首帧向量 RMS 为 0.595727/1.236360 mm/s，
> 全窗为 0.489406/0.891793 mm/s；原始报告、训练种子、选解轨迹和 13 组图均已冻结。
> 不同窗口、分量/向量 RMS 以及不同参考粗粒化下的数值不可直接排名。

此次工作是源码独立化和结果复现，没有进行新一轮长训练或生产级正向模拟。仓库只保留当前统一方法的运行实现。

已核实：

- 五个算例（周期 1.5/4/10 mm/s、CF261/505）以保存的选中初态重新推进；场系数、输出速度和逐片段验证似然与原记录的最大绝对差均为 **0**。
- 23 个独立数据文件进行了尺寸和 SHA256 校验。
- 捕获态混合概率、自由态相关高斯密度、原始相机区间协方差的数学检查通过。
- 训练目标小批次前向/反向/一步更新正常；周期和 CF 的反演自动微分与有限差分一致；两者各完成四阶段单步优化短测。
- 正向模拟完成 0.2 ms 无粒子 CPU 短测和随后 0.1 ms 有粒子 CPU 短测，保存了 VTKHDF。短测明确为未达到稳态，不作物理生产结果。
- 重新完成五个算例的留出评价、VTKHDF 导出和八组论文绘图，输出在 `runs/baseline/Results/`。
- 从源码 ZIP 解压到独立目录，显式禁止读取原项目源码，仅允许指定的独立数据包和基线结果；五个算例仍全部通过场与似然一致性验证。

本机测试结果：`8 passed`（包含数据集成测试）；公开仓库 CI 没有研究数据时会跳过三项数据集成测试，运行五项独立检查。CPU 正向短测通过；CUDA 服务器运行、GitHub 远程 CI 和完整新一轮重训未在此次整理中执行。

`verification.json` 是逐算例核对记录；`figure_manifest.json` 是重绘记录。数据包中保留详细输出，源码仓库内仅保留这些小型验证证据。

源码中没有动态插入旧项目路径，也没有旧日期目录的运行导入。缺失的关键函数从本项目的历史补丁找回后，抽取到具有明确职责的模块中；没有把聊天记录打包到仓库。`source_provenance.json` 只记载源文件相对路径及哈希。

三处既有事实需要保留：

1. 旧源码部分已不在原位置，本次通过历史补丁恢复必要函数，并以已保存的数值输出验证其一致性。
2. 原始 Excel→缓存、原始模拟→训练张量的完整独立预处理器尚未交付。本版本可从冻结观测/训练张量开始复现，不声称覆盖任意新原始输入。
3. 冻结旧对照初态由既有对照场在相同有限基中反解获得；用于重新评分和绘图，不作为新重建初始化。基底回代误差小于 1e-10 m/s。

CF 固定噪声律、相机/插值差异、当前模型科学局限及原开发数据的反复使用均未因源码整理而消失。
