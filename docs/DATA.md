# 数据与复现边界

> 当前正式模拟基线的数据协议见 [FullWindow](FULLWINDOW_BASELINE.md)。其服务器输入包
> 约 12.54 GiB，九工况、原始 1 ms 轨迹与完整保存场；不包含在 Git 中。
> Git 只保留约 6 MiB 的冻结模型/初态/证据，足以独立 PDE 回放，不足以重新训练。
> 下文的 1.44 GiB 数据包及清单仅对应历史统一/CF 路径，不能用于冒充本次完整重训数据。

代码、约 40 KB 的当前模型权重及配置可直接进入 GitHub。研究数据与运行产物不进入 Git。当前导出的独立数据包约 1.44 GiB，共 23 个文件，以 `config/data_manifest.json` 的尺寸和 SHA256 为准。

```text
data/
├── inputs/          # 五个 (合并观测窗, 各子窗) .pt 包
├── operators/       # 周期/固壁 K12 正向算子及空间加密检查算子
├── training/        # 六模态条件场的训练/验证视图
├── calibration/     # 保留工况的物理解码标定张量
└── evaluation/      # 仅评估读取的参考场和冻结对照
```

所有观测包里的算子路径是相对于数据目录的路径。使用 `--data PATH` 或 `COUNTERFLOW_DATA` 改变数据位置。运行目录使用 `--run PATH` 或 `COUNTERFLOW_RUN` 指定。路径不会回退搜索原作者电脑或任何旧分支。

观测包含：`pid`、局部时间索引 `frame`、位置 `x`、历史位移 `w`、目标位移 `target`、轨迹历史 `h`、固定物性特征 `context`、候选场在观测点的基底值/梯度 `V/G` 及背景 `v0/g0`。CF 自由态另含因果原始相机区间的 `weights`、`native_times`、`target` 与路径采样信息。`decode` 将初态控制映射为 PDE 系数；`initial` 仅提供形状，优化从零扰动开始。

参考场文件与冻结比较初态放在 `evaluation/`。训练、标定和反演模块没有读取它们的代码。`evaluate` 要求全部选解冻结后才使用它们。原始三维 VFM 不参与这条发布路线。

当前基线与新训练使用的自由态解码器完全相同。自由态噪声标定是确定的，与捕获态网络权重无关。`calibrate` 会重新计算噪声律，检查标定数据哈希与自由态噪声律一致后复用相关系数；若这些条件改变则拒绝复用，需要重新提供自由态时间残差标定数据。

**原始数据预处理的已知边界：**旧的 Excel→观测包重导出入口依赖已缺失的三维项目模块。该入口未包装为可用功能。发布版本从已保存、已校验的观测包开始；不宣称任意新 Excel、任意新模拟都能自动转换为上述训练/观测张量。新正向模拟可独立运行，新增数据进入训练前仍需实现符合该契约的统一预处理器。这是已有流程的缺口，而不是新的预测模型。

本地 `runs/baseline/` 含验证选中的初态、候选记录及重绘结果。源代码包不包含此目录；可用 `python scripts/package.py data --output ../counterflow-data.zip` 将数据和基线运行记录单独打包供服务器复现。数据包没有默认公开下载地址。不要在公共仓库中提交未经授权的实验原始文件。

`.pt` 文件只应来自可信的本项目数据包；完整包以清单哈希核验。当前加载器保留原有 PyTorch 序列化格式，不将未知 `.pt` 文件视为安全的数据交换格式。
